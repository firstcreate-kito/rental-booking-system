# Stripe 銀行振込 運用メモ（将来の操作マニュアル用）

Stripe の銀行振込（customer_balance / jp_bank_transfer＝お客様ごとに発行する
振込専用口座）についての運用上の注意点。将来、操作マニュアルを作成するときの
下書きとして残す。

---

## 1. 土日に入金しても「反応がない」のは正常（最重要）

**観察された事象**：土日の間にお客様が振込をしても、システム・Stripe ともに
すぐには「入金済み」にならない。

**理由（仕様）**：
- 日本の銀行振込は**銀行営業日（平日）にしか着金処理されない**。土日祝は
  銀行側で処理が動かないため、Stripe が着金を認識するのも**翌営業日以降**になる。
- システムの「入金確定 → 予約確定 → 領収書発行」は、Stripe からの
  **Webhook（`charge.succeeded` / async payment succeeded）**をトリガーに動く。
  着金が認識されるまで Webhook は飛ばないので、その間はシステムも無反応で正常。

**したがって**：
- 金曜夜〜日曜に振込 → **月曜（祝日なら翌営業日）**に反映されるのが通常。
- お客様から「振り込んだのに確定メールが来ない」と問い合わせがあっても、
  週末・祝日をはさむ場合は**翌営業日まで待てば自動で確定する**ことが多い。
- 数営業日を過ぎても反映されない場合のみ、下記の手動確認を行う。

---

## 2. 反映を待つ間、枠はどうなっているか

- 銀行振込・請求書払いは予約時点で **confirmed（赤枠・カレンダー確保）** される。
  未入金でも枠は押さえられているので、待っている間にダブルブッキングは起きない。
- 未入金のまま放置された枠は Cron が自動解放する（#39）。解放条件は
  「**作成から10日** または **ご利用日の前日** の早い方」。
  - 週末をはさんで着金が数日遅れても、利用日まで余裕があれば解放されない。
  - ただし**ご利用日の前日**になっても未入金だと自動キャンセルされるため、
    利用直前の振込は間に合わないことがある（受付は利用日の7日前まで）。

---

## 3. 反映されない時の確認手順（管理者）

1. **Stripe ダッシュボード**で対象の取引を確認する。
   - 「支払い」→ 該当のお客様／金額で検索。ステータスが
     `処理中（processing）`＝まだ着金待ち、`成功（succeeded）`＝着金済み。
2. `succeeded` なのにシステムが未確定の場合は、Webhook の取りこぼしの可能性。
   - Stripe ダッシュボードの「開発者 → Webhook」でイベントの配信状況を確認。
3. それでも確定しない場合は、システム管理画面から**手動で入金確定**の操作を行う
   （支払いステータスを「入金済み」に更新）。

> ※金額の実確認・口座名義などは本番稼働時に実地確認する（課題 #92）。

---

## 4. お客様への案内で明記していること（現状）

予約時に自動送信される「お支払い待ち」メールに、以下を記載済み：
- 振込先・払込番号は **Stripe（決済代行）から届くメール**に記載されること。
- **期限内に入金がないと自動的にキャンセル**になること。
- 入金確認後にあらためて確定メール・領収書を送ること。

（コンビニ払いも同じ骨子。請求書払いは「当社発行の請求書」を参照する文面に分岐。）

---

## 5. マニュアルに載せると良い一言（案）

> 銀行振込は銀行の営業日にしか着金しません。土日祝をはさむお振込は、
> 翌営業日に自動で「予約確定」となり、確定メールと領収書が届きます。
> それまでは画面・メールに変化がなくても正常です。
