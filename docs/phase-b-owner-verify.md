# オーナー向け・目視確認ガイド（Phase B：変更・キャンセルの承認フロー / ステージング）

デプロイ後、ステージング（`https://albe-booking-api-staging.rental-space-albe.workers.dev`）でこの手順に沿ってご確認ください。
前提：確認用テスト予約を複数の残日数で用意（当日／前日／数日後／8日以上先）。会員・管理者の両方でログインできる状態に。

## ① 会員：キャンセル申込（マイページ）
1. 対象予約の「キャンセル」を開く。
2. 画面に**キャンセル料・返金額が表示**される。
   - 防音室/東別院：8日以上前=無料／2〜7日前=50%／前日・当日=100%
   - 標準：31日前まで無料／30〜15日前50%／14〜前日80%／当日100%
3. 「申請」する。
4. ✅ OK基準：「申請を受け付けました（金額は担当者確認後に確定）」表示／**予約カレンダーの枠が空く（即時反映）**／**顧客・管理者の両方に受付メール**。

## ② 会員：日時変更申込（マイページ）
1. 対象予約の「日時変更」で新しい日時を選ぶ。
2. **返金/追加請求/「キャンセル扱い」の金額が表示**される。
   - 前日より前(標準)／前々日より前(防音室)=無償
   - 当日(標準)・当日/前日(防音室)=「キャンセル扱い（旧返金なし・新満額）」の警告
   - 増やす=追加請求／減らす=返金
3. 「申請」する。
4. ✅ OK基準：カレンダーで**旧枠が空き・新枠がブロック**／顧客・管理者双方に受付メール。

## ③ 管理画面：承認
1. 「精算待ち」一覧に①②が出る。
2. 各件に**金額入力枠**があり、**顧客に出した金額がプリセット**されている。
3. 金額を任意に変更 → 「**承認**」。
4. ✅ OK基準：正式確定（変更後予約の確定／キャンセル確定）／支払方法別に処理（④）／顧客・管理者双方に確定メール／「差し戻し」も可能。

## ④ 支払方法ごとの結果（メールを確認）
- 返金・カード/PayPal … 自動返金の案内
- 返金・銀行振込/コンビニ … 「返金先口座を返信してください」メール
- 増額・カード/PayPal … 「追加料金＋決済リンク」メール
- 増額・銀行振込/コンビニ … 「増額＋振込リンク」メール
- 返金も請求も無い時（無償変更・返金0・チケット）… 「完了しました」メールのみ

## ⑤ チケット予約
- キャンセル：前々日まで=時間が戻る／当日・前日=失効（現金0）
- 変更：前々日以前=全額戻して取り直し／当日・前日で時間そのまま=無償／減らす=減少分失効／増やす=不可（新規予約の案内）

## ⑥ クーポン
- クーポン（新規登録¥500など）を使った予約をキャンセル → クーポン残が戻り再利用できる。

## ⑦ 念のため（壊れていないか）
- 通常の新規予約・決済（カード/振込/コンビニ）が従来どおり。
- Googleカレンダー反映が従来どおり。
