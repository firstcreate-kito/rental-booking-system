## 1. 一言でいうと

レンタルスペースALBEの予約サイトを、**予約から支払い・変更・領収書発行・会員特典まで、すべてオンラインで完結できる自社予約システム**に刷新しました。
（URL：https://booking.space-albe.com ／ 対象：ALBEの各スペース）

## 2. お客様メリット（ブログの主軸）

### ① 予約がかんたん・スムーズ
- **2か月表示のカレンダー**で空き状況がひと目でわかる。スマホでも見やすい。
- 開始・終了時刻を**選ぶだけ**（30分刻み）。初期は1時間利用で表示。
- 会員なら**「いつもの予約」ワンクリック再予約**（前回と同じ条件をすぐ呼び出し）。
- **空き状況ページ**で、予約する前に空きだけをサッと確認できる。

### ② 支払い方法が豊富
- **クレジットカード／PayPal**（即時決済）
- **銀行振込／コンビニ払い**（スペースにより対応）
- **請求書払い**（法人・団体向け／スペースにより対応）
- スペースごとに使える支払い方法が最適化されているので、迷わず選べる。

### ③ 会員になると、もっとおトク・便利
- **ポイントが貯まる／使える**（利用に応じて付与）。
- **クーポン**の利用に対応。
- **回数券（チケット）**の購入・利用に対応（対象スペース）。
- **マイページ**で、予約履歴の確認、**領収書・請求書のPDF発行**、ポイント残高の確認ができる。
- **Google／LINEアカウントでログイン**できるので、登録も再ログインもラク。

### ④ 変更・キャンセルもオンラインで完結、しかも透明
- 予約の**変更・キャンセルをマイページから申請**できる（電話やメールのやり取り不要）。
- 申請時に**発生する金額（差額・返金額・キャンセル料）を事前に画面で確認**してから「承認して送信」。あとから想定外の請求が来ない安心感。
- **返金は、カード・PayPalは自動**で処理。銀行振込・コンビニは担当が確実に対応。

### ⑤ 領収書・請求書がすぐ手に入る
- マイページから**領収書・請求書をPDFで自分で発行・ダウンロード**できる。経費精算がスムーズ。

### ⑥ 予約まわりの案内が手厚い
- 予約確定・入金確認・利用前リマインダー（3日前／1日前）など、**必要なタイミングで自動メール**が届く。
- スペース固有の**入室方法・解錠番号などの案内**を、確定したお客様向けメールに自動で差し込み。
- **トラブルシューティングページ**を用意（予約がうまくできないときの自己解決ガイド）。

### ⑦ ダブルブッキングを徹底防止＝安心
- 予約台帳をGoogleカレンダーで一元管理し、**複数の経路からの予約が重ならない多層的な仕組み**で、予約の取り合い・重複を防止。

### ⑧ ゲスト（会員登録なし）でも予約OK
- 会員登録せずに予約したい方は**ゲスト予約**（カード即時決済）に対応。
- ゲストの予約でも、**本人確認のうえ変更申請**が可能。

### ⑨ 安心・プライバシー配慮
- 不正防止（CAPTCHA・ログイン保護）や、個人情報の適切な保持・匿名化ポリシーなど、安全面にも配慮。

## 3. 主な機能一覧（詳細・記事の肉付け用）

- **予約フロー**：スペース選択 → 2か月カレンダー → 時間選択（30分刻み）→ オプション → お客様情報 → 支払い。利用目的・利用人数・利用規約同意などの入力に対応。
- **決済**：Stripe（カード／銀行振込／コンビニ）、PayPal、請求書払い。即時決済＝決済先行、後払い＝仮押さえ（未入金時の自動整理あり）。
- **会員機能**：メール登録／ログイン、Google・LINEログイン、パスワード再発行、マイページ（予約履歴・書類発行・ポイント・クーポン・チケット）。
- **ポイント**：利用に応じて付与、1年ローリングの有効期限、失効・期限接近の案内メール。
- **回数券（チケット）**：購入・利用、有効期限の接近案内、キャンセル方針あり（対象スペース）。
- **変更・キャンセル**：統一ポリシー＋スペース別の柔軟ポリシー、オンライン申請＋金額の事前明示、承認制。
- **返金／追加請求**：カード・PayPalは自動返金、銀行振込・コンビニは手動対応、差額の追加請求リンク発行。
- **書類**：領収書・請求書のPDF発行（最終金額での再発行にも対応）。
- **通知メール**：予約確定、内容変更、利用前リマインダー、キャンセル、入金確認、未入金リマインダー、会員登録（ウェルカム）、回数券購入、利用後のお礼、ポイント／チケット期限接近、など。
- **スペース別の細かな設定**：追加質問、通知先、入室案内文、Google口コミ導線、画像、支払い方法プリセット。
- **空き状況ページ**：日付起点で空きを確認。公式サイトへの空き状況カレンダー埋め込みにも対応。
- **現地サイネージ（新規・運用向け）**：各スペースのモニターに本日の予約状況を表示（※お客様メリットというより現地運用の利便。記事では触れなくてもよい）。

## 8. 付録：正確な値・ポリシー（記事で数値を書くとき用）

- **支払い方法**：カード（Stripe）／PayPal／銀行振込（Stripe）／コンビニ払い／請求書払い。**対応可否はスペースごとに設定**。
- **ログイン**：メール＋パスワード、Google、LINE。
- **ポイント**：利用に応じて付与、**有効期限は1年（ローリング）**、失効前に案内メール。
- **回数券（チケット）**：対象スペースで購入・利用。**キャンセル方針＝前々日まで返還／前日・当日は失効**。有効期限接近の案内メールあり。
- **キャンセル料（標準ポリシー）**：31日前まで無料／30〜15日前 50%／14日前〜前日 80%／当日 100%。
  - **一部スペース（防音室・ピアノ練習室など）は特別ポリシー**：8日以上前 無料／2〜7日前 50%／前日・当日 100%。
  - ※日時変更は空き状況しだいで無料の場合あり。
- **返金時の手数料**（変更・キャンセルで返金が生じる場合）：
  - カード／PayPal 決済：**返金額の3.7%＋消費税10%**を差し引き。
  - 銀行振込／コンビニ／請求書払い：**一律 ¥350＋消費税10%**を差し引き。
  - ※手数料が返金額を上回る場合、**返金額は0円**（マイナスにはならない）。
  - ※返金額・計算式は申請画面と案内メールに明示。
- **予約可能／閲覧可能期間**：スペース設定に依存（既定で最大180日先まで空き閲覧）。
- **ゲスト予約**：会員登録なしで予約可（カード即時決済）。本人確認のうえ変更申請可能。
