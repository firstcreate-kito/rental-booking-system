# キャンセル・変更ポリシー（スペース別）WEBサイト更新 引継ぎ資料

- 対象: レンタルスペースALBE WEBサイト（space-albe.com）／予約システム（booking.space-albe.com）
- 目的: 予約システム側で導入した「**スペース別キャンセルポリシー＋変更は無料**」の方針を、WEBサイトのポリシー表記に反映するための引継ぎ。
- 作成日: 2026-08-24 ／ 関連バックログ #99・#100

---

## 0. 基本の考え方（今回の方針）

**「変更（日時をずらす）はやさしく＝無料／キャンセル（取りやめ）はスペース別に厳しく」**

- 予約の**日時変更**は、空き状況に応じて**無料**で承ります（直前でもOK）。別の枠に移るだけで店の損失が小さいため。
- **キャンセル**は、直前ほどキャンセル料が発生します。料率は**スペースにより異なります**。

---

## 1. キャンセルポリシー（スペース別）

### 標準（多くのスペース：名駅フリースペース ほか）
| 時期（利用日から） | キャンセル料 |
|---|---|
| 31日前まで | 無料 |
| 30〜15日前 | 50% |
| 14日前〜前日 | 80% |
| 当日 | 100% |

### 特別（**名駅防音室A／B・東別院ピアノ練習室**）
直前予約・変更が多いピアノ練習室系のための特別ルール。
| 時期（利用日から） | キャンセル料 |
|---|---|
| 8日以上前 | 無料 |
| 2〜7日前 | 50% |
| **前日・当日** | **100%** |

> ※どのスペースがどのポリシーかは、予約システムの管理画面で設定します（将来、対象スペースが増減する可能性があります）。**現時点の特別対象＝名駅防音室A／B・東別院ピアノ練習室**。

---

## 2. 変更（日時変更）ポリシー

- **日時のご変更は、空き状況に応じて無料で承ります**（直前でもご相談ください）。
- 変更は「変更リクエスト → スタッフ確認」で確定します（お客様の操作だけでは確定しません）。
- **注意（抜け穴防止）**: 変更後にキャンセルされた場合、キャンセル料は**当初のご利用日を基準**に計算します（遠い日へ変更してから無料キャンセル、はできません）。

---

## 3. オンライン受付の締切（共通）

- **キャンセル**：利用日の**3日前まで**はオンライン（マイページ／変更ページ）で受付。**3日前以降はメールフォーム・お電話**でのみ受付。
- **日時変更**：オンラインで随時受付（リクエスト送信 → スタッフ確認）。

---

## 4. 予約システム側の画面挙動（参考）

- お客様が「キャンセル」を選ぶと、**発生するキャンセル料・ご返金額を実額で自動表示**し、「同意する」にチェックしないと送信できません（#100）。
- 表示金額は**手数料（カード手数料等）を含まない実額**です（最終確認・返金手続きはスタッフが実施）。
- 未入金（振込前など）の予約は返金0円と表示されます。

## 6. 運用メモ（管理者向け・システム側の有効化手順）

このポリシーは**本番反映（`npm run deploy`）後**に、管理画面で各スペースへ設定して有効化します。

1. 管理画面 → 「スペース設定」→ 対象スペース（名駅防音室A／B・東別院ピアノ練習室）を「編集」。
2. 「キャンセルポリシー（このスペース）」で **「ピアノ練習室特別（8日以上前=無料／2〜7日前=50%／前日・当日=100%）」** を選択。
3. 「保存」。→ 以後、そのスペースのキャンセル料・#100の金額表示がこの料率で計算されます。
4. 他スペースは「標準（共通）」のまま。
