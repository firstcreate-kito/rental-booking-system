# LINEログインの有効化手順（オーナー作業）

システム側（マイページの「LINEでログイン」ボタンと認証処理）は実装済みです。
あとは **LINE Developers で「ログイン用チャネル」を登録して鍵を設定するだけ**で有効になります。
鍵を設定するまではボタンは自動的に非表示のままなので、既存のログインには影響しません。

> ⚠️ **重要**：このシステムはメールアドレスで会員を識別します。そのためLINEログインでも
> **メールアドレスの取得が必須**です。手順C（メールアドレス取得権限の申請）を必ず行ってください。
> これを行わないと、ボタンは表示されてもログイン時に「メールアドレスが登録されていないため…」
> というエラーになります。

---

## A. LINE Developers でチャネルを作成

1. [LINE Developers Console](https://developers.line.biz/console/) にLINEアカウントでログイン（会社のLINEアカウント推奨）。
2. **プロバイダー**を選択（無ければ「作成」。名前は会社名「株式会社ファーストクリエイト」など。※後で顧客の同意画面に表示されます）。
3. 「新規チャネル作成」→ **「LINEログイン」** を選択。
   - チャネルの種類：**LINEログイン**
   - チャネル名：**レンタルスペースALBE**（※顧客の同意画面に表示されます）
   - チャネル説明：例「レンタルスペースALBEのマイページ用ログイン」
   - アプリタイプ：**ウェブアプリ** にチェック
   - メールアドレス・利用規約等に同意して「作成」

---

## B. コールバックURLを設定

1. 作成したチャネルを開き、**「LINEログイン設定」** タブへ。
2. **「コールバックURL」** に次を**そのまま**追加（重要・完全一致）：
   ```
   https://booking.space-albe.com/api/auth/line/callback
   ```
   - 「更新」を押して保存。

---

## C. メールアドレス取得権限を申請（必須）

1. 同じチャネルの **「LINEログイン設定」** タブ内、**「OpenID Connect」→「メールアドレス取得権限」** の
   **「申請」** を押します。
2. 申請には **プライバシーポリシーのURL** が必要です。次を入力：
   ```
   https://space-albe.com/privacy/
   ```
   （※貴社サイトのプライバシーポリシーページのURL。異なる場合は実際のURLに置き換えてください）
3. 同意画面の内容を確認し、申請を確定します。**通常はすぐに「適用済み」**になります。

---

## D. 鍵（Channel ID / Channel secret）を確認

1. チャネルの **「チャネル基本設定」** タブを開きます。
2. **チャネルID**（数字）と **チャネルシークレット**（英数字）をコピーします。

---

## E. システムに鍵を設定（PowerShell）

プロジェクトフォルダ（`C:\Users\kyton\rental-booking-system`）で、1行ずつ実行します。
実行すると値の入力を求められるので、コピーした値を貼り付けて Enter（画面には表示されません）。

```
npx wrangler secret put LINE_CHANNEL_ID
```
→ **チャネルID**（数字）を貼り付け → Enter

```
npx wrangler secret put LINE_CHANNEL_SECRET
```
→ **チャネルシークレット**を貼り付け → Enter

その後、反映のためデプロイ：
```
npm run deploy
```

---

## F. 動作確認

1. `https://booking.space-albe.com/mypage.html` を開く。
2. ログイン画面に **「LINEでログイン」ボタン**（緑）が表示される（鍵設定後に自動表示）。
3. 押す → LINEの同意画面 → 許可 → 戻ってきて**ログイン完了**。
   - 初めてのメールなら、その場で会員登録も兼ねます。

うまくいかない場合、画面に日本語のエラーが出ます。よくある原因：

- **コールバックURLの不一致**（手順B）：末尾スラッシュ・スペル・httpsの有無まで完全一致か確認。
- **「メールアドレスが登録されていないため…」**：手順C（メールアドレス取得権限）が未申請、または
  お客様がLINEにメール未登録／同意画面でメール提供を拒否した場合に出ます。まずは手順Cの「適用済み」を確認してください。

エラー文言と、LINE Developers のコールバックURL設定のスクショをいただければ調整します。

---

## メモ（技術）

- 認証方式：LINE Login v2.1（OAuth 2.0 / OpenID Connect・Authorization Code）。`openid profile email` を取得。
- コールバック：`/api/auth/line/callback` でトークン交換 → id_token からメール確認 →
  既存のマジックリンク方式でマイページにログイン（1回限りトークン）。CSRF対策に `state` を使用。
- id_tokenは aud（チャネルID）・iss（`https://access.line.me`）・exp を検証。
- 鍵は `wrangler secret`（暗号化保存）で管理。コードやGitには含めません。
- 費用：**無料**（LINEログインの利用料はかかりません）。
- 同じ考え方で、後日 Yahoo! JAPAN ID も追加できます（別途登録）。
