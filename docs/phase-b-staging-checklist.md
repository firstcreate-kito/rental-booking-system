# Phase B ステージング検証チェックリスト（変更・キャンセルの承認フロー）

- 対象：`docs/unified-change-cancel-policy.md` の実装（Phase B）
- 環境：`https://albe-booking-api-staging.rental-space-albe.workers.dev`
- 準備：管理者ログイン／テスト会員／テスト予約を**複数の残日数**で用意（当日・前日・前々日・7日前・8日前・15日前・31日前 など）。標準スペース（名駅フリー）と特別スペース（名駅防音室A/B・東別院）両方。

> 金額はいずれも「申込画面で提示 → 管理画面の承認で確定」。承認時に管理者が金額を任意変更できることも確認する。

## 1. キャンセル料（現金予約・標準スペース）
- [ ] 31日以上前：返金**全額**（キャンセル料0）
- [ ] 30〜15日前：**50%**キャンセル料
- [ ] 14日前〜前日：**80%**
- [ ] 当日：**100%**（返金0）

## 2. キャンセル料（防音室A・B／東別院）
- [ ] 8日以上前：**無料**
- [ ] 2〜7日前：**50%**
- [ ] 前日・当日：**100%**

## 3. 日時変更（標準スペース）
- [ ] 前日より前・同じ時間数の移動：**無償**（返金/請求なし・完了メール）
- [ ] 当日：**キャンセル扱い**（旧予約は返金0＋新予約は満額請求）＝画面で警告表示

## 4. 日時変更（防音室A・B／東別院）
- [ ] 前々日より前：**無償**
- [ ] 当日・前日：**キャンセル扱い**（警告表示）

## 5. 変更の増額・減額
- [ ] 増額（時間追加）：差額が**追加請求**として計上（決済/振込リンク発行）
- [ ] 減額（時間短縮・無償期間）：短縮分を**全額返金**
- [ ] 減額（キャンセル料50%の時期）：短縮分の**50%だけ返金**

## 6. 申込＝即時反映（枠・カレンダー）
- [ ] キャンセル申込 → **その場で枠が解放**（カレンダーが空く）
- [ ] 変更申込 → **新枠がブロック・旧枠が解放**（カレンダーが移動）
- [ ] 申込後の画面表示「申請を受け付けました。金額は担当者の確認後に確定します」

## 7. 管理画面：承認フロー
- [ ] 「精算待ち」一覧に申込が表示される
- [ ] **金額入力枠に顧客提示額がプリセット**されている
- [ ] 金額を**任意に変更**できる
- [ ] 「承認」で正式確定（返金/追加請求/完了が実行）
- [ ] 「差し戻し」ができる（メモを残せる）

## 8. 承認後アクション（支払方法別）
- [ ] 返金・カード/PayPal：**自動返金**が実行される
- [ ] 返金・銀行振込/コンビニ：**返金先口座を返信してもらうメール**が届く
- [ ] 増額・カード/PayPal：**追加料金の明示＋決済リンク**が届く
- [ ] 増額・銀行振込/コンビニ：**増額の明示＋振込（決済）リンク**が届く
- [ ] 返金/請求なし（無償変更・返金0キャンセル・チケット）：**「完了しました」メールのみ**

## 9. メールは顧客＋管理者の双方
- [ ] 申込時：顧客「申請受付」／管理者「承認待ち発生（要対応）」
- [ ] 承認時：顧客「確定（返金/追加請求/完了）」／管理者「確定実行（控え）」
- [ ] 管理者宛先が**スペース別通知設定（#72）**に従う

## 10. チケット予約
- [ ] キャンセル・前々日まで：チケット時間を**全額返還**（現金0）
- [ ] キャンセル・当日/前日：チケット時間**失効**（現金0）
- [ ] 変更・前々日以前：**全額返還**して新枠で再消費
- [ ] 変更・当日/前日・増減なし：無償で付替（返還なし）
- [ ] 変更・当日/前日・減少：減少分は**失効**
- [ ] 変更・当日/前日・増加：**受け付けない**（「追加分は新規予約を」と案内）

## 11. クーポン返却
- [ ] クーポン（例：新規登録¥500）を使った予約をキャンセル → **クーポン残が戻る**（再利用できる）

## 12. 旧ゲートの廃止
- [ ] キャンセルが**3日前以降でもオンライン申込できる**（フォーム誘導に飛ばされない）

## 13. リグレッション（壊れていないこと）
- [ ] 通常の新規予約・決済（カード/PayPal/振込/コンビニ）が従来どおり
- [ ] Googleカレンダー同期が従来どおり
- [ ] 既存の管理画面（予約一覧・代理予約・商談中・返金・追加請求）が従来どおり
- [ ] `npx vitest run` 全 green ／ `test/policy-lock.test.ts` green（ポリシー未破壊）

## 14. ゲスト予約（今回対象外の確認）
