## 1. 料金モデル（確定）

### 1.1 時間帯別料金の廃止
- v2.0 の「時間帯別料金（午前 / 午後 / 夜間）」の概念は**全廃**。
- 廃止テーブル: `time_zones`、`space_time_zone_pricing`。
- 料金は「**1時間あたりの単価（平日 / 土日祝）**」に一本化する。

### 1.2 スペース料金の持ち方
各スペースは以下を持つ（`spaces` テーブルに統合）:

| 項目 | 内容 |
|------|------|
| `weekday_rate` | 平日の1時間単価 |
| `weekend_rate` | 土日祝の1時間単価 |
| `day_rate_hours` | **1日料金を「何時間分」で計算するか**（任意 / NULL可） |
| `billing_type` | `'hourly'`（時間貸し） or `'block'`（1日単位専用） |

### 1.3 1日料金の考え方
- 1日料金は「**時間数**」で定義する（例: 営業14時間のスペースで `day_rate_hours = 13` なら 13時間分の料金＝1時間分お得）。
- 平日 / 土日祝の別は、それぞれの単価 × `day_rate_hours` で自動計算。
- **発動条件**:
  - `billing_type = 'hourly'`: **営業時間ちょうど全部**（`open_time`〜`close_time`）を選択したときのみ1日料金へ差し替え。部分予約は通常の時間料金。`day_rate_hours` が NULL のスペースは1日料金なし（常に時間料金）。
  - `billing_type = 'block'`: **何時間の予約でも常に1日料金**（1日単位専用スペース）。

#### 計算例（営業 08:00–22:00 = 14時間、平日単価 ¥1,000、`day_rate_hours = 13`）
| 予約 | 計算 | 金額 |
|------|------|------|
| 10:00–16:00（6時間） | 6 × ¥1,000 | ¥6,000（時間料金） |
| 08:00–22:00（全営業時間） | 13 × ¥1,000 | ¥13,000（1日料金） |

### 1.4 残置（ざんち）＝ホテル泊数方式
- 連日予約で荷物・什器を残す場合、予約時に「残置しますか？」と**意思確認**（チェックボックス）。
- 残置を選ぶと、荷物を翌日に持ち越す日は**1日料金**を適用（スペースを丸一日占有するため）。
- **どの日に1日料金がかかるか**:
  - **初日〜中間日**（翌日に荷物を持ち越す日）＝ 1日料金
  - **最終日**（すべて引き上げる日）＝ 通常の時間料金
- 例: 4/20・4/21 連日（各 10:00–18:00）で残置あり → 4/20 = ¥13,000（1日料金）、4/21 = ¥8,000（時間料金）。
- 発想は**ホテルの宿泊（泊数で販売）**と同じ。

### 1.5 予約状態区分（更新）
予約枠の状態は次の4区分に整理:

| 区分 | 表示（顧客カレンダー） | オンライン予約 | 備考 |
|------|----------------------|--------------|------|
| 本予約 `confirmed` | 青 | 不可（満枠時） | 通常の確定予約 |
| 商談中 `tentative` | 黄系「商談中」 | 不可（問い合わせ誘導） | 後述の新機能 |
| 休業 | グレー | 不可 | 休業日 |
| 内部ブロック `blocked` | ✕ 満室 | 不可 | GCal外部追加など |

## 2. 割引・チケット・ポイント（確定）

### 2.1 割引クーポン
- `discount_type`（percent / fixed）＝割引の内容。
- `total_hours` / `remaining_hours`＝**割引を適用できる時間の上限**。使った分だけ残時間が減る。
- 例: 「20%OFF・残5時間」で3時間予約 → 3時間分に20%OFF、残5→2時間。

### 2.2 チケット
- 残時間内は ¥0。
- **残時間を超えた分は通常料金で課金**（例: 残2時間で5時間予約 → 2時間¥0＋超過3時間は通常料金）。

### 2.3 1日料金との兼ね合い
- 1日料金の予約にチケット / クーポンを使う場合、**消費する時間は課金対象の時間**（実占有14時間ではなく、`day_rate_hours` の13時間）。

### 2.4 ポイント
- 付与: 支払額の1%（`status = 'completed'` 時）。
- **完了への遷移は利用日の翌日に自動**（日次バッチで、前日までに利用済みの予約を `completed` に更新しポイント付与）。

### 2.5 割引の併用ルール（確定）
- 割引の主役は **クーポン / チケット / ポイント / なし** のいずれか1つ。
- スペース料金（＋残置料金）のみが割引対象。**オプションは常に割引対象外**。

| 主な割引 | キャンペーン | 備考 |
|----------|-------------|------|
| なし | フル適用 | |
| クーポン | 不可 | クーポン優先。超過時間分も満額（キャンペーンなし） |
| チケット | 超過分のみ | 残時間内は¥0、超過分にキャンペーン適用可 |
| ポイント | **不可** | ※v2.0の「ポイント+キャンペーン併用可」を上書き |

- **①** クーポン残時間を超えた分は満額（キャンペーンも不可）。
- **②** チケット残時間を超えた分にキャンペーン適用。
- **③** ポイント使用時はキャンペーン対象外。
- **④** ポイントはスペース料金（＋残置料金）のみ。オプション不可。使用量は会員指定（残額まで）。
- **⑤** チケット/クーポンの充当順は **高い時間帯（土日祝など）から先に充当**（お客様の割引額が最大になる）。

## 3. 新機能：仮予約（商談中）

### 3.1 目的
- アルベホール名古屋・名駅フリースペース等、**複数日の予約を営業担当が手動でハンドリング**するケースに対応。
- 「満室✕」ではなく「**商談中**」と見せることで、「まだチャンスあり」と伝わり**問い合わせにつなげる**。

### 3.2 仕様（確定）
- 営業担当が**管理画面から仮予約を作成**。
- 予約状態に `tentative`（商談中）を追加。
- 顧客カレンダーには常に「**商談中**」と表示（本予約とは別の見た目）。
- 商談中の枠は**オンライン予約不可**。問い合わせへ誘導。
- **有効期限は設けない**。営業担当が手動で「本予約化」または「解除」。
- **全スペース対象**（実際に使うかは運用判断）。
- **サイネージには表示しない**（確定予約のみ表示）。

## 5. 認証・インフラ・外部連携（確定）

### 5.1 認証
- パスワード保存: **PBKDF2（WebCrypto）**。Cloudflare Workers で標準的に利用可能な方式。
- 管理者セッション: v2.0 に定義漏れがあったため、**管理者用セッション管理を追加**（`admin_sessions` 等）。

### 5.2 インフラ
- **Cloudflare アカウントは未契約** → 当面は**ローカル環境（Wrangler + ローカル D1）で開発**。契約後にデプロイ。
- **Google**: 管理者アカウントあり。

### 5.3 Google Calendar
- 各スペースの**既存の稼働中カレンダーに連携**（新規作成不要）。
- 双方向同期（システム→GCal / GCal→システム Webhook + ポーリング）は v2.0 の設計を踏襲。

### 5.4 メール / 書類PDF
- 予約確認等のトランザクションメール: **Resend を推奨**（無料枠3,000通/月、Workers と相性良）。要望に応じて GAS 経由へ変更可。
- 請求書・領収書PDF: 既存GASは頓挫のため**新規構築**（Googleドキュメントのテンプレート → PDF生成方式を想定）。

### 5.5 LINE通知
- **後のフェーズに延期**。初期はメールのみ。

### 8.2 料金モデルの確定
- **1日料金 = day_rate_hours(=13) × 適用1時間単価**。全スペースで「1日料金 ÷ 1時間料金 = 13.0」が成立することを実データで確認。
- 1日料金は「時間数（13）」で保持し、平日/土日祝の単価に自動追従する（`spaces.day_rate_hours`）。
- 単価は**NULL許容**とし、「その曜日区分では貸し出さない」を表現できるようにした（`spaces.weekday_rate` / `weekend_rate`）。
- スペースに**曜日区分ごとの提供可否**を追加（`spaces.weekday_available` / `weekend_available`）。

### 8.3 個別スペースの特記
- **北岡崎倉庫スペース**: 土日祝のみ営業（平日は貸出なし）、最長7時間、**時間料金5,500円のみ（1日料金なし）**。締切は利用日の5日前。受付開始(horizon)は暫定180日前（運用で調整可）。
- **東別院防音室24時間**: 受付開始180日前・締切は直前予約可（当初の「5日前まで」は誤記）。

### 8.4 税
- **料金表の金額はすべて税込み表示**。料金計算エンジンは税込み金額を扱う。
- 請求書・領収書（Phase 3）で税抜・消費税(10%)の内訳が必要になった場合は、税込み金額から割り戻して表示する。

### 8.5 実装状況（Phase 1）
- 料金計算エンジン（スペース料金）を `src/lib/pricing.ts` に実装。
  - 時間料金 / 1日料金(全営業選択・残置) / 最低利用 / 曜日区分・祝日 / 季節料金 / 連日検出 に対応。
  - `test/pricing.test.ts` にて実料金表と一致することを検証（15ケース）。
- 割引クーポン・チケット・ポイント・キャンペーン・オプションは次段で実装予定。
