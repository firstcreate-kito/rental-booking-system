## 日時変更ポリシー

### 名駅フリースペース ほか（標準）
| 時期 | 扱い |
|---|---|
| 前日より前 | 無料で変更できます |
| 当日 | キャンセル扱い（100%） |

### 名駅防音室A・B／東別院24h
| 時期 | 扱い |
|---|---|
| 前々日より前 | 無料で変更できます |
| 当日・前日 | キャンセル扱い（100%） |

- **時間を増やす**変更：差額を追加でお支払い。
- **時間を減らす**変更：短縮した分にキャンセル料率（上記）を適用してご返金。
- 「キャンセル扱い」とは：元のご予約は返金なし＋新しいご予約は満額、という扱いです。

---

## チケット（回数券）でのご予約
現金でのキャンセル料・追加請求はありません（常に¥0）。

- **キャンセル**：前々日まで＝チケット時間を全額返還（再予約に使えます）／前日・当日＝失効（返還なし）。
- **日時変更**：前々日より前＝全額返還して取り直し／当日・前日で同じ時間数＝無料で振替／時間を減らす＝減少分は失効／時間を増やす＝新規予約でお取りください。

---

## 具体例

- 名駅フリー ¥33,880（7時間）を **8日前にキャンセル** → キャンセル料 80%＝**¥27,104**／ご返金 **¥6,776**
- 名駅フリー ¥33,880（7時間）を **8日前に5時間へ短縮** → 短縮分 ¥9,680 の 80% がキャンセル料／ご返金 **¥1,936**
- 名駅防音室A を **前日にキャンセル** → キャンセル料 **100%**（ご返金なし）
- 名駅フリー を **当日に日時変更** → キャンセル扱い（元予約は返金なし＋新予約は満額）
