# 【WEBチーム引継ぎ】予約フォームの「入力途中の自動保存」— プライバシーポリシー追記用

予約システム（`booking.space-albe.com`）の予約フォームに、**入力途中の内容を
自動保存し、次に開いたときに「続きから入力」できる機能**を追加しました。
個人情報を一時的に端末へ保存するため、WEBサイトのプライバシーポリシーに
その旨を記載していただく必要があります。**そのまま貼れる文面**を下にご用意しました。

---

## 1. そのまま貼れる文面（プライバシーポリシー本文）

> ### 入力途中データの一時保存について
>
> 当施設の予約フォームでは、お客様がご入力の途中でページを離れた場合でも、
> 次回同じ端末・同じブラウザでアクセスされた際に続きから入力を再開できるよう、
> ご入力中の内容（ご利用スペース・日時・お客様情報・ご回答いただいた項目など）を、
> **お客様がお使いの端末（ブラウザ）内にのみ**一時的に保存します。
>
> - この保存には、Cookie ではなく **ブラウザのローカルストレージ**を使用します。
> - 保存された内容は**お客様の端末内にのみ**保管され、当社サーバーや第三者へは送信されません。
> - **予約が完了した時点**、または**保存から24時間が経過した時点**で、
>   保存内容は**自動的に削除**されます。
> - 予約フォーム上の「破棄」ボタンから、お客様ご自身でいつでも削除できます。
> - **パスワード、クレジットカード等のお支払い情報、ご利用規約への同意状況は保存しません。**
>
> 共用のパソコン等をご利用の場合は、予約完了後または離席前に、
> ブラウザの閲覧データ消去、または当フォームの「破棄」ボタンでの削除をおすすめします。

※ 文体・見出しレベルはサイト側の既存プライバシーポリシーに合わせて調整してください。
　（内容は変えないようにお願いします。）

---

## 2. 技術的な補足（社内確認・監修用。掲載は不要）

正確性の確認のため、実装の事実を記載します。プライバシーポリシー本文への転記は不要です。

| 項目 | 内容 |
|---|---|
| 保存の仕組み | ブラウザの **localStorage**（Cookie ではない） |
| 保存キー | `albe_booking_draft` |
| 保存する内容 | スペースID／選択した日時（カート）／オプション数量／予約方法の区分／お客様情報（イベント名・利用目的・利用人数・過去利用・きっかけ・姓・名・メール・電話・会社名・請求書宛名）／スペース別追加質問への回答 |
| **保存しない内容** | **パスワード／クレジットカード等の決済情報／ご利用規約への同意（毎回チェックし直し）／会員ログインのパスワード** |
| 保存の範囲 | お客様の端末内のみ。サーバー・第三者へは送信しない |
| 自動削除① | **予約完了時**（決済ページへ移動する場合も含む）に削除 |
| 自動削除② | **保存から24時間**が経過していたら、次回アクセス時に自動削除（古い個人情報を端末に残さないため） |
| 手動削除 | 「続きから入力」バナーの**「破棄」ボタン**でお客様が削除可能 |
| 他機能との違い | ログイン維持（sessionStorage）や会員登録後の復帰（別キー）とは別の仕組み |

- 個人情報保護の観点から、24時間の自動失効・完了時削除・決済/パスワード非保存を
  安全策として組み込んでいます。
- 主な利用は個人のPC・スマートフォンを想定しています。共用端末での利用に備え、
  上記の文面に「共用端末では削除をおすすめする」旨を含めています。

---

## 3. サイト側の作業まとめ

1. 上記「1.」の文面を、サイトのプライバシーポリシーに1項目として追記する。
2. 見出しレベル・文体を既存ポリシーに合わせる（内容は変更しない）。
3. Cookie 同意バナー等を運用している場合でも、本機能は Cookie を使わないため
   Cookie の分類追加は不要。ただし「端末内保存（ローカルストレージ）」を明記する
   ポリシーであれば、その分類に含めてください。
